## Модуль 4. Алгоритмы и структуры данных

| Уровень | Решение | Как работает |
| --- | --- | --- |
| 1 | [Бинарный поиск](module_4/binary_search.py) | После сравнения со средним элементом область поиска сокращается вдвое. Время O(log n). |
| 2 | [Сортировка вставками](module_4/insertion_sort.py) | Вставляет очередное значение в отсортированную часть списка. В худшем случае время O(n²). |
| 3 | [Поиск в ширину](module_4/breadth_first_search.py) | Очередь позволяет обойти вершины по расстоянию от начальной. Для списков смежности время O(V + E). |

В каждом файле есть пример запуска. Например, команда `python module_4/binary_search.py` выведет индекс `3`.

## Запуск

Из корня репозитория выполните команду для нужного файла. Например, для задачи про МКАД:

```powershell
python module_1/part_1/level_2.py
```

Введите скорость и время на отдельных строках. При вводе 30 км/ч и 5 часов программа выведет 41 — отметку на дороге длиной 109 км.
