# Модуль 6. Процессы и потоки

Уровни 1 и 2 реализованы в [threads.py](threads.py).
Функция get_thread принимает имя, ждёт секунду и печатает его.
Программа сравнивает пять последовательных вызовов с пятью потоками.
Все потоки запускаются до ожидания их завершения через join.

Уровень 3 реализован в [web_pages.py](web_pages.py).
Функция get_html получает текст страницы через requests.
Пять разных URL загружаются последовательно, затем в пуле из пяти потоков.
Результаты извлекаются до завершения замера. Ошибки запросов передаются вызывающему коду.

Из корня репозитория выполните

```powershell
python -m pip install -r module_6/requirements.txt
python module_6/threads.py
python module_6/web_pages.py
```

Библиотека называется requests. Для первого скрипта достаточно стандартной библиотеки.
Время измеряется через time.perf_counter в секундах. Порядок печати имён потоков может меняться.
Ускорение загрузки страниц зависит от сети и сервера. Повторные запросы и кэширование могут влиять на сравнение.

При контрольном запуске ожидание заняло 5.002 с последовательно и 1.005 с в потоках. Загрузка пяти страниц заняла 4.485 с и 1.186 с соответственно. Это результаты одного запуска, время на другом компьютере может отличаться.
