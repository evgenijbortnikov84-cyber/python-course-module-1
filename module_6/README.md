# Модуль 6. Процессы и потоки

## Уровни 1 и 2

[threads.py](threads.py): get_thread(thread_name) ждёт одну секунду через time.sleep(1), затем печатает имя. Пять разных имён передаются сначала последовательным вызовам, затем пяти потокам Thread. Сначала запускаются все потоки, затем join ожидает завершения каждого. Если запускать поток и сразу вызывать join в одном цикле, параллельного ожидания не получится.

Время обоих вариантов измеряется через time.perf_counter в секундах. Во время ожидания другие потоки могут работать, поэтому пять ожиданий примерно по секунде перекрываются.

## Уровень 3

[web_pages.py](web_pages.py): get_html(link) получает текст страницы через requests.get, проверяет HTTP-статус и возвращает response.text. Ответ закрывается после чтения. Задан тайм-аут 20 секунд для сетевых операций; это не общий лимит всей программы. Ошибки соединения и HTTP не скрываются.

Пять разных URL загружаются последовательно и через ThreadPoolExecutor(max_workers=5). list(pool.map(...)) получает все результаты внутри замера. Размер ответа указан в символах, не в байтах. Содержимое страниц между двумя запросами может измениться.

Библиотека называется **requests**, а не request.

## Запуск

Из корня репозитория:

```powershell
python -m pip install -r module_6/requirements.txt
python -X utf8 module_6/threads.py
python -X utf8 module_6/web_pages.py
```

Для threads.py достаточно стандартной библиотеки. Для web_pages.py нужны requests и доступ в интернет. Параметр -X utf8 позволяет сохранять русский вывод в файл без ошибки кодировки Windows.

## Проверки

```powershell
python -X utf8 -B -m unittest discover -s tests -p test_module_6.py -v
python -X utf8 -B -m unittest discover -s tests -v
```

[Шесть тестов](../tests/test_module_6.py) проверяют секундное ожидание, печать имени, пять отдельных потоков, пять разных URL, получение текста, HTTP-ошибки и тайм-аут. В тестах сетевые ответы подменяются, чтобы проверки не зависели от доступности сайта. Барьер синхронизации проверяет одновременный запуск пяти рабочих потоков; короткое время теста не выдаётся за реальный сетевой замер.
