# Модуль 5

Выполнены все задания двух файлов, включая дополнительные задания о воинах.

| Задание | Решение |
| --- | --- |
| Часть 1, уровень 1 | [StringVar с set и get](part_1/string_var.py) |
| Часть 1, уровень 2 | [Point с перемещением и расстоянием](part_1/point.py) |
| Часть 1, уровень 3.1 | [Бой двух воинов](part_1/warrior.py) |
| Часть 1, уровень 3.2 | [Арена с защитой, бронёй и выносливостью](part_1/arena.py) |
| Часть 2 | [Model.save и пример Article](part_2/model.py) |

Запускайте из корня репозитория, например `python module_5/part_1/arena.py`.
Для модели используйте `python module_5/part_2/model.py`. В текущей папке появится article.json.

Для Point выбраны методы перемещения и вычисления расстояния, поскольку конкретный набор методов в условии свободный.

В арене поражение наступает при здоровье 10 или меньше. Атаки раунда одновременны, при поражении обоих объявляется ничья. Решение о помиловании запрашивается для каждого проигравшего. Помилование при нулевом здоровье оставляет 1 очко.
Сила удара определяется по выносливости перед атакой. При нулевой выносливости урон 0–10, в том числе против брони. Броня теряется только при защите от атаки. Все показатели ограничены снизу нулём.

Model сохраняет публичные атрибуты класса и экземпляра, включая унаследованные. Методы и служебные атрибуты пропускаются. Значения должны поддерживать JSON. Повторное сохранение заменяет содержимое указанного файла.
