## StringVar и Point

StringVar вызывает set из конструктора, чтобы проверка типа была в одном месте. Некорректное присваивание не меняет прежнее значение. Подчёркивание в _value обозначает внутренний атрибут по соглашению Python.

Point сравнивает координаты через __eq__. Для другого типа возвращается NotImplemented. Сравнение точное, без допуска для дробных чисел. hypot вычисляет расстояние по двум разностям координат и устойчивее прямого возведения в квадрат при очень больших числах.

## Общий Warrior и арена

Warrior хранит здоровье, принимает урон через take_damage и выполняет простой удар на 20 единиц. Методы не печатают. Здоровье доступно для чтения через свойство; изменение выполняется методами. Победитель простого боя хранится явно в winner. random.sample выбирает двух разных участников и возвращает их в случайном порядке.

ArenaWarrior наследует Warrior и добавляет броню, выносливость и защиту. Дублирования базового класса нет. Атакующий подготавливает Hit с вариантами силы удара. Получатель в take_damage сам выбирает вариант по собственной защите и броне. Отрицательные значения урона отклоняются; здоровье, броня и выносливость не опускаются ниже нуля.

Правила из задания:

- Два воина, начальные здоровье, броня и выносливость по 100.
- Действия выбираются случайно. Это автоматическая симуляция, а не управление действиями игроком.
- Атака расходует 10 выносливости. Проверяется выносливость до удара.
- Обычный урон от 10 до 30; при защите с бронёй от 0 до 20, потеря брони от 0 до 10.
- При нулевой выносливости урон от 0 до 10, в том числе против брони.
- Поражение при здоровье 10 или меньше. Это порог задания, а не универсальное правило игр.
- Удары подготовлены до применения урона. Оба удара выполняются даже при поражении обоих в текущем раунде. Тогда объявляется ничья.
- Помилование сохраняет оставшееся здоровье, а при нуле оставляет 1. Это решение после завершения партии, а не новый раунд.

Arena хранит двух участников, источник случайности и порог поражения. round() возвращает события ударов. result() возвращает исход либо None, если бой продолжается. play() проводит партию без ввода и печати. При превышении лимита раундов выдаётся RuntimeError, чтобы источник с постоянной защитой не вызвал бесконечный цикл.

RandomSource содержит отдельный random.Random(seed). Интерфейс для подстановки в тестах: choose_action() возвращает «атака» или «защита»; roll_damage(bounds) возвращает целое число внутри включённых границ. Один и тот же seed воспроизводит партию. Все параметры удара выбираются заранее, поэтому последовательность случайных чисел отличается от старой версии, но диапазоны правил сохранены.

```python
from module_5.part_1.arena import Arena, ArenaWarrior, RandomSource

arena = Arena([ArenaWarrior("Первый"), ArenaWarrior("Второй")], RandomSource(42))
result = arena.play()
print(result.winner.name if result.winner else "Ничья")
```

Для новой партии создайте новую Arena и новых воинов. Три участника отклоняются явно: задание рассчитано на двух, а для троих потребовались бы отдельные правила выбора цели.

## Model.save и Model.load

Подкласс задаёт словарь fields: имена сохраняемых полей и их типы. Article сохраняет title, text и author. Значения по умолчанию остаются атрибутами класса, как в задании. Изменения отдельной статьи хранятся в экземпляре. vars(self) не включил бы неизменённые атрибуты класса; dir(self) с getattr мог вызвать посторонние свойства. Здесь читаются только явно указанные поля, остальные свойства не вызываются. Не включайте вычисляемые свойства в fields.

save возвращает None. Сначала проверяет данные и сериализует их, затем пишет временный файл в том же каталоге и заменяет целевой файл. Так ошибка записи не оставляет прежний файл наполовину перезаписанным. try/finally охватывает запись и закрытие, а не только replace. Удаление временного файла выполняется и при сбое записи или замены. Ошибки доступа передаются вызывающему коду. Это защита от частичной записи, не гарантия сохранности при отключении питания и не механизм разрешения одновременных изменений несколькими процессами.

На POSIX при замене сохраняются прежние биты прав доступа. Для нового файла выбрана политика 0600, доступ владельцу; автоматического расширения до 0644 нет. Владение и дополнительные ACL отдельно не копируются. На Windows права определяются ACL каталога. Проверка POSIX-прав на Windows пропускается.

Article.load(path) проверяет JSON, точный набор полей и типы, затем возвращает новую статью. Конструктор модели должен допускать вызов без аргументов. Некорректный JSON или структура вызывают ValueError; отсутствие файла вызывает FileNotFoundError; другие ошибки файловой системы сохраняют тип OSError.
