## Бинарный поиск

`binary_search(numbers, target)` принимает список по возрастанию. Порядок заранее обеспечивает вызывающий код. При повторах возвращается любое найденное вхождение, при отсутствии цели -1.

Лучший случай O(1), худший O(log n), память O(1). Для миллиона элементов достаточно не более 20 проверок середины, поскольку 2²⁰ = 1 048 576.

## Сортировка вставками

`insertion_sort(numbers)` меняет исходный список и возвращает None. Сортировка по возрастанию, без параметров key и reverse.

Стабильность обеспечивается строгим сравнением >. Равные элементы не перемещаются друг через друга. На отсортированном списке время O(n), на случайном порядке различных значений в среднем O(n²), на обратном порядке O(n²). В худшем случае выполняется n(n - 1)/2 сдвигов. Дополнительная память O(1).

```python
numbers = [5, -2, 5, 1]
insertion_sort(numbers)
print(numbers)
```

## Поиск в ширину

- `breadth_first_search(graph, start)` возвращает порядок обхода.
- `breadth_first_search_details(graph, start)` возвращает порядок, расстояния и предшественников.
- `shortest_path(graph, start, target)` возвращает кратчайший путь по количеству рёбер. Для отсутствующей или недостижимой цели возвращает None.

Граф задаётся словарём со списками соседей. Вершины должны быть пригодны для ключей словаря. Вершина может находиться только среди соседей. Неизвестная начальная вершина вызывает ValueError. Если начало совпадает с целью, путь содержит одну вершину.

При нескольких равных по длине путях результат зависит от порядка соседей. Очередь deque извлекает начало за O(1). Отметка при добавлении исключает повторную постановку вершины. Время O(V + E), память O(V). Проверка существования начальной вершины просматривает также недостижимую часть графа.
