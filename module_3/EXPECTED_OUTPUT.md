# Ожидаемые результаты модуля 3

Примеры ниже показывают результат без приглашения к вводу. Полные строки вывода, включая приглашения, проверяются в tests/test_module_3.py, класс ProgramTests. Ввод через `;` в таблице означает отдельные строки.

| Задание | Ввод | Ожидаемый результат |
| --- | --- | --- |
| Вклад | 100; 121; 10 | 2 |
| Вклад без роста | 100; 200; 0 | Цель недостижима |
| while | 2 | Две строки: for - частный случай цикла while |
| Сумма цифр | -507 | 12 |
| Повторения | [1, 4, 1, "hello", "hello"] | [1, 'hello'] |
| Максимум матрицы | [[9, 70], [100, 1]] | 100 |
| Группировка имён | {"Анна": "id1", "Иван": "id1"} | {'id1': ['Анна', 'Иван']} |
| Площадь | 3 4 5 | 6.0 |
| Короткие слова | Кот из-за don't и мышь | ['Кот', 'и', 'мышь'] |
| Максимальное число | 3 30 34 5 9 | 9534330 |
| Регистрация | Новое имя и допустимый пароль | Пользователь создан |
| Повторная регистрация | То же имя | Логин занят |
| Вход | Сохранённое имя и верный пароль | Вход выполнен |
| Неверный пароль или битая запись | Ошибочные данные | Ошибка входа |

## Список покупок

После добавления «белый хлеб 2» и двух позиций «шампунь 1» команда «показать» выводит:

```text
белый хлеб 2
шампунь 2
```

Ожидания в tests/test_shopping_list.py изменены с 2.0 на 2, с 1.0 на 1. Дробный результат по-прежнему проверяется как `яблоки 1.75`.

При вводе «хлеб», «хлеб много», «хлеб -1», «хлеб 0» или «хлеб nan»:

```text
Ошибка: введите название и положительное число, например хлеб 2
```

После этих ошибок ввод «хлеб 2» успешно добавляет позицию.

## Ошибочные данные

| Программа | Ввод | Результат |
| --- | --- | --- |
| while | 0 или буквы | Ошибка: введите положительное целое число |
| Сумма цифр | буквы | Ошибка: введите целое число |
| Матрица | [[]] | Ошибка: нужна непустая числовая матрица без пустых строк |
| Треугольник | 1 2 | Ошибка: Введите ровно три стороны |
| Треугольник | 1 2 3 | Ошибка: Такие стороны не образуют треугольник |
| Максимальное число | -12 5 | Ошибка: Разрешены только неотрицательные целые числа |
| Максимальное число | пустая строка | Ошибка: Введите хотя бы одно число |

Ошибки консольного ввода завершаются сообщением без traceback. Неуспешный тест, в отличие от ошибки пользовательского ввода, завершает unittest с ненулевым кодом.
