# Ожидаемые результаты модуля 3

Примеры показывают результат без приглашения к вводу. Полные строки проверяются в tests/test_module_3.py. Точка с запятой в таблице означает новую строку ввода.

| Задание | Ввод или пример | Результат |
| --- | --- | --- |
| Вклад | 100; 121; 10 | 2 |
| Вклад без роста | 100; 200; 0 | Ошибка: Цель недостижима при заданных условиях |
| Ограничение расчёта | 1000000; 1e30; 0.001 | Ошибка: Цель не достигнута за 10000 лет; расчёт остановлен |
| while | 2 | Две строки: for - частный случай цикла while |
| while | 0 | Ничего не выводится, ошибки нет |
| Сумма цифр | -507 | 12 |
| Повторения | Запуск встроенного примера | [1, 'hello'] |
| Максимум матрицы | Запуск встроенного примера | 100 |
| Имена и id | Запуск встроенного примера | {1: ['Анна', 'Иван'], 2: ['Анна']} |
| Площадь | 3 4 5 | 6.0 |
| Короткие слова | Кот из-за don't; пустая строка; и мышь; конец ввода | ['Кот', 'и', 'мышь'] |
| Максимальное число | 3 30 34 5 9 | 9534330 |
| Регистрация | Новое имя и допустимый пароль | Пользователь создан |
| Повторная регистрация | То же имя | Логин занят |
| Вход | Сохранённое имя и верный пароль | Вход выполнен |
| Неверный пароль или битая запись | Ошибочные данные | Ошибка входа |

Часть 2 больше не требует JSON-ввода. Данные редактируются в коротком примере внизу файла или передаются функции. Проверка find_duplicates([1, True, 1.0, "1"]) даёт пустой список: эти четыре значения различаются по типу.

Для коротких слов завершите ввод: Windows - Ctrl+Z и Enter; Linux/macOS - Ctrl+D. Пустая строка не завершает ввод.

## Список покупок

После добавления «белый хлеб 2» и двух позиций «шампунь 1»:

```text
белый хлеб 2
шампунь 2
```

Количество 0.5 + 1.25 выводится как 1.75, а 0.5 + 1.5 как 2. Строки «хлеб», «хлеб много», «хлеб -1», «хлеб 0» и «хлеб nan» дают:

```text
Ошибка: введите название и положительное число, например хлеб 2
```

## Ошибочный ввод

| Программа | Ввод | Результат |
| --- | --- | --- |
| while | -1 или буквы | Ошибка: введите неотрицательное целое число |
| Сумма цифр | буквы | Ошибка: введите целое число |
| Треугольник | 1 2 | Ошибка: Введите ровно три стороны |
| Треугольник | 1 2 3 | Ошибка: Такие стороны не образуют треугольник |
| Максимальное число | -12 5 | Ошибка: Разрешены только неотрицательные целые числа |
| Максимальное число | пустая строка | Ошибка: Введите хотя бы одно число |

## Проверки

Модуль 3: 50 тестов. Список покупок: ещё 5 тестов. Все проходят без пропусков.
Общий набор: 112 тестов, из них один тест прав POSIX модуля 5 пропускается на Windows. Итог: `OK (skipped=1)`.

Время выполнения меняется; фактический отчёт находится в [TEST_RESULTS.txt](TEST_RESULTS.txt). Тесты проверяют ограничение числа лет, нулевой цикл, различие типов, сохранение пар, многострочный ввод, транзитивность сравнения, версии аккаунтов, старый формат, Unicode, границу длины пароля и повтор регистрации после сбоя.
